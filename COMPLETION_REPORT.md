## 🧮 Data Structures & Algorithms

### All 5 Algorithms Implemented

| Algorithm | Data Type | Time | Space | Use Case |
|-----------|-----------|------|-------|----------|
| **BST** | Binary Search Tree | O(log n)* | O(n) | Book catalog search |
| **HashMap** | Hash Table | O(1)* | O(n) | User preference lookup |
| **Stack** | LIFO Structure | O(1) | O(n) | Reading history |
| **Queue** | FIFO Structure | O(1) | O(n) | Book reservations |
| **MergeSort** | Sorting Algorithm | O(n log n) | O(n) | Recommendation ranking |

*Average case; worst case O(n) if unbalanced
