## 🔑 Key Concepts

### The 5 Core Algorithms

1. **Binary Search Tree (BST)** 🌳
   - Used for: Book catalog search
   - Time: O(log n)
   - Reference: [PSEUDOCODE_REFERENCE.md Section 1](PSEUDOCODE_REFERENCE.md#1-binary-search-tree-bst)

2. **Hash Map** 📍
   - Used for: User preferences lookup
   - Time: O(1)
   - Reference: [PSEUDOCODE_REFERENCE.md Section 2](PSEUDOCODE_REFERENCE.md#2-hash-map-dictionaries)

3. **Stack** 📚
   - Used for: Reading history (LIFO)
   - Time: O(1)
   - Reference: [PSEUDOCODE_REFERENCE.md Section 3](PSEUDOCODE_REFERENCE.md#3-stack-last-in-first-out---lifo)

4. **Queue** 🚶
   - Used for: Book reservations (FIFO)
   - Time: O(1)
   - Reference: [PSEUDOCODE_REFERENCE.md Section 4](PSEUDOCODE_REFERENCE.md#4-queue-first-in-first-out---fifo)

5. **Merge Sort** 🔄
   - Used for: Ranking recommendations
   - Time: O(n log n)
   - Reference: [PSEUDOCODE_REFERENCE.md Section 5](PSEUDOCODE_REFERENCE.md#5-merge-sort)
